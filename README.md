# Sistema de Vendas com Python

Projeto desenvolvido como parte da aula prática **Jornada Python**, da [Hashtag Programação](https://www.hashtagtreinamentos.com/).

O objetivo é reproduzir um sistema de gerenciamento de vendas utilizando Python, aplicando conceitos de manipulação de dados, desenvolvimento de interfaces web e visualização de informações.

> **Créditos e autoria:** Este projeto é baseado integralmente no conteúdo didático e nas orientações da Hashtag Programação. O desenvolvimento original e a proposta do projeto pertencem à Hashtag. Este repositório tem finalidade exclusivamente educacional, servindo como registro dos meus estudos e da prática dos conceitos apresentados na aula.

## Funcionalidades

- Cadastro de vendas por meio de formulário interativo.
- Registro de data, vendedor, produto, quantidade e valor.
- Armazenamento dos dados em arquivo CSV.
- Exibição do histórico de vendas em tabela interativa.
- Dashboard com indicadores de faturamento.
- Gráficos para análise de vendas por vendedor e produto.

## Tecnologias utilizadas

- **Python:** linguagem de programação.
- **Streamlit:** desenvolvimento da interface web.
- **Pandas:** manipulação e análise de dados.
- **Plotly:** criação de gráficos interativos.

## Como executar o projeto

1. Clone este repositório:

   ```bash
   git clone URL_DO_REPOSITORIO
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd NOME_DO_REPOSITORIO
   ```

3. Instale as dependências:

   ```bash
   pip install -r requirements.txt
   ```

4. Execute a aplicação:

   ```bash
   streamlit run main.py
   ```
